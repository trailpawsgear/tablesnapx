One table split across several pages?

Tick the pages involved, in order, then pick how they go together. If one page has a few extra rows the others don't (a title, a repeated label), use "skip" to drop them so the rows line up before you merge. Nothing here is guessed automatically, you tell it what the pages are to each other, and you check the result in the preview before trusting it.

Works best on PDFs that were produced digitally (exported from Excel, a web page, an invoicing tool), where the text itself can be read directly. A PDF that is really a scanned photo of a page has no text to read and will not produce a table here. Merged cells and unusually shaped tables may not line up perfectly, always check the preview before trusting the export.

The PDF is read and processed entirely in your browser, nothing is uploaded anywhere.
